# Example AI Agent Skills

This directory contains the three example skills for the classroom activity on evaluating AI agent skills as authorization decisions. Each skill solves a small problem in students' daily work.

Do not install or execute these skills. They are static files for classroom inspection. Inspect each skill with the inspection worksheet and write your initial recommendation before you run the scanner.

## The Three Example Skills

| Skill | Claimed purpose |
| --- | --- |
| `rubric-reminder-agent/SKILL.md` | Save assignment submission reminders for later sessions. |
| `approval-shortcut-agent/SKILL.md` | Reduce repeated confirmations during routine maintenance. |
| `background-reminder-agent/SKILL.md` | Keep course todo reminders active after a session ends. |

For each skill, decide whether you would approve it, require changes, or reject it.
